## Capture Host

Test-only:

```text
FirstFrameCaptureDisplayHost
```

Captured state:

```text
DisplaySize
redraw_count
present_count
first_frame: Option<RgbaFrame>
```

Semantics:

```text
resize
-> records size only

request_redraw
-> increments redraw count only
-> does not create a frame

first present_rgba8
-> increments present count
-> stores first_frame

later present_rgba8
-> increments present count
-> never overwrites first_frame
```

This makes first-frame observation deterministic even when later animation/repaint activity occurs.
