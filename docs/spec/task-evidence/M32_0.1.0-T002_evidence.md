# M32 0.1.0-T002 Evidence — Native GPU Renderer

Status before verification: IMPLEMENTED / NOT YET ACCEPTED

## Scope
- Adds `m32-display::DisplayRenderer`.
- Pins `egui-wgpu 0.36.1` and `wgpu 30.0.1`.
- Owns native surface/device/queue through `egui_wgpu::winit::Painter`.
- Handles zero-size resize safely.
- Relies on Painter's surface reconfigure/recreate path.
- Registers wgpu device-loss callback and lets desktop recreate the renderer.
- Does not upload real guest frames yet. That belongs to later First Playable tasks.

## Boundary
`m32-desktop` talks to `m32-display`; it does not manipulate raw wgpu objects.
