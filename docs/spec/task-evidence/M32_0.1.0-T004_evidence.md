# M32 0.1.0-T004 Evidence — Desktop Keyboard -> Guest Input Pump

Status before human verification: IMPLEMENTED / NOT YET ACCEPTED

## Scope

Desktop physical-key defaults are wired into the existing `m32-input::GuestInputController`:

```text
Arrows -> D-pad
Enter/NumpadEnter -> OK
Z/X -> Left/Right soft key
Esc -> CLR
0-9 / numpad 0-9 -> numeric keys
A -> *
S -> #
```

OS-generated key-repeat events are ignored. M32's existing deterministic policy remains authoritative:

```text
350ms delay
12Hz repeat
max six held
duplicate suppression
stable held-key repeat order
```

## Automated proof

The composed runtime launches the existing M32-owned `KeyMidlet/KeyCanvas` JAD+JAR fixture, sends Up
through the `GuestInputController`, pumps the product runtime, and requires real guest stdout sentinels:

```text
M32_KEY_PRESSED:141;
M32_KEY_RELEASED:141;
```
