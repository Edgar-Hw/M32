## Canonical proof

The M32-owned First Playable fixture is launched through the full desktop/product composition path against one temporary M32 application root.

```text
launch composed runtime
-> observe counter 0 frame
-> guest key input
-> Java RecordStore saves counter 1
-> observe changed RGBA8 frame
-> destroy complete PlayableRuntime
-> rebuild complete PlayableRuntime against same M32 root
-> guest reports M32_FP_RUNNING:1
-> first restored RGBA8 frame exactly matches the previously saved visible frame
```

The test never calls `m32-storage` directly. Persistence is only reached through `PlayableRuntime` -> `WiePlatformHosts` -> existing persistent guest hosts.
