# M32 0.1.0-T003 Evidence — Live Frame Presentation Loop

Status before human verification: IMPLEMENTED / NOT YET ACCEPTED

## Scope

The live path is:

```text
WIE guest paint
-> RgbaFrame
-> LiveDisplayHost latest-frame revision
-> desktop egui texture update
-> Pixel Perfect integer-scaled viewport
```

`EmulatorSession::handle_redraw` is a backend-agnostic host redraw seam. `WieSession` maps it to the
pinned WIE `Event::Redraw`. `LiveDisplayHost` keeps replacing the latest frame instead of freezing the
first captured frame.

No CRT/LCD filtering is introduced.
