## FIX1 — Deterministic Advancing Clock

Pinned MIDP `EventQueue::getNextEvent()` sleeps for 16ms when the backend event queue is empty.

Pinned WIE executor sleeping tasks only resume when backend time advances to their wake deadline.

The existing synthetic host used:

```text
FixedClock
```

which deliberately returned a constant epoch.

Sequence:

```text
EventQueue sees empty queue
-> sleep 16ms
-> host receives redraw request
-> host forwards Event::Redraw
-> platform time never advances
-> sleeping EventQueue task never wakes
-> redraw remains queued
-> Canvas.paint never runs
-> presents=0
```

Added test-only:

```text
DeterministicAdvancingClock
```

T006 runtime configuration:

```text
start epoch: 1_725_123_456_789
step:        +1ms per epoch_millis() call
```

Existing `FixedClock` semantics remain unchanged.

Regression:

```text
deterministic_advancing_clock_moves_forward_for_sleeping_tasks ... ok
```

After FIX1:

```text
first_frame_paint_fixture_ticks_until_guest_frame_is_captured ... ok
```

The first real guest-generated frame reached M32.
